# Architecture Decision Records

ADRs capture material decisions and their consequences. Files in this folder are **proposed** until reviewed against the existing repository and accepted by the project owner or designated architecture process.

## Statuses

- Proposed
- Accepted
- Superseded
- Deprecated
- Rejected

Accepted ADRs take precedence over conflicting draft feature text. Do not edit accepted history to disguise a changed decision; add a superseding ADR.
