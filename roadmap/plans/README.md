# Plans and Traceability

- `initial-backlog.yaml` orders draft epics and tasks by dependency. Repository-specific estimates and module paths must be added after audit.
- `requirements-register.csv` is the initial product and engineering requirement register.
- `traceability-matrix.csv` maps requirements to planned tests and fixtures.
- `test-catalogue.csv` defines an initial set of test artifacts and expected evidence.

Statuses are drafts. Accepted requirements should be reviewed, prioritized, and linked to real issues in the implementation repository.
