# Examples

All examples in this folder are invented for this documentation pack and do not reproduce third-party maps.

- `simple-map.json` exercises graph identity, a composite, metrics, two projections, two views, a timeline, and a scenario.
- `simple-story.json` references the example map and demonstrates two story chapters with private speaker notes excluded by default.
- `composite-collapse-test.json` is an algorithm-focused expected-result fixture rather than a full strategic-map document.

The schemas are drafts. Referential and domain constraints such as unique IDs, valid endpoints, acyclic membership, keyframe order, and cross-file story references require validation beyond structural JSON Schema.
